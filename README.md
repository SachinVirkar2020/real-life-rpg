# LIFE RPG
Mobile-first offline RPG task tracker.
- Each task has Start and Done actions. Start marks In Progress and previews its XP and next reward target. Done marks Completed and adds XP.
- XP is accumulated from completed tasks only.
- 350 = 1 game card; 400 = 1 game + 1 level-up; 450 = 1 game + 1 level-up + 1 anime episode; 500+ = 2 games + 1 level-up + 1 anime episode.
- Higher same-day milestones issue only the additional reward difference.
- Animated RPG popups appear on quest start, quest completion and milestone unlock.
- Reward cards remain available until opened; opening marks them used.
- Anime titles are editable by weekday. Data is stored locally in browser/WebView storage.
